 
# Campus Restaurant Recommendation System

A university course project combining a C-based restaurant recommendation program with Python utilities for location selection, distance processing, and map visualization.

## Project Components

- `restaurant_recommender.c` — C-based restaurant recommendation program.
- `main_ui.py` — Python graphical interface.
- `choose_location.py` — Location selection utility.
- `show_route.py` — Route visualization.
- `show_top5_map.py` — Top-five restaurant map visualization.
- `update_route_distances.py` — Restaurant distance data processing.
- `Restaurant_core.csv` — Core restaurant data.
- `Restaurant_runtime.csv` — Runtime restaurant data.

## Technologies

- C
- Python
- CSV data processing
- GUI and map visualization

## Project Notes

This repository contains code and data from a university course project. Some features may require additional Python packages, local configuration files, or external map and geolocation services.

Please review the source files for specific execution requirements before running the project.
